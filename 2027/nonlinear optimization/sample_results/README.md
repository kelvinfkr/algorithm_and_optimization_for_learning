# 参考运行记录

这里保存讲义制图和交付验证使用的真实运行记录，供学生在没有训练环境时阅读，也用于复核默认实验协议。完整机器可读索引见 [validation.json](validation.json)，人工阅读摘要见 [VALIDATION.md](VALIDATION.md)。

| 目录或文件 | 内容 |
|---|---|
| `foundations/exact_examples.json` | 二次模型、预算投影的精确参数和 KKT 证书 |
| `lab01/` | seed=2027 的解析矩曲线、Monte Carlo 数据与 batch 缩放数据 |
| `lab02/` | seed=2027 的全部9个优化器配置、训练诊断和选定配置 |
| `lab03/` | seed=2027 的全部36个参数化/宽度/学习率配置与过程诊断 |
| `seed2028/`、`seed2029/` | 另外两个种子的 Lab2/Lab3 完整配置和最终结果 |
| `checks/math_checks.json` | 六个独立数值核验模块的结果 |
| `notebook_execution.json` | 三个 Notebook 在 Jupyter 内核中的执行记录 |

所有模型数据均由脚本本地合成；目标的标准化只使用训练集统计量。每份实验 JSON 都保留配置与环境。默认使用 CPU、float64（PyTorch 实验），因此这些记录不构成 GPU 计时结果。

## 如何解释这些结果

优化器比较的单种子最优值来自各自预先声明的三个候选配置，不表示已经找到每种方法的全局最优超参数。不同优化器的更新单位不同，因此学习率数值不能脱离算法定义比较。

宽度实验在部分种子上选择了网格边界的候选，JSON 的 `selection_at_grid_boundary` 已明确标记。在这些情形下，尚不能定位最佳学习率；后续应扩展预先声明的扫描范围，再运行所有比较组。初始有效核一致、特征移动尺度相近与测试误差改善分别是不同问题，不能相互替代。

PNG/PDF 图中的曲线仅为这些有限设置的记录。平均值和标准差可以描述种子波动，但三个种子与一个合成任务不足以支持普遍的优化器或参数化优劣结论。

若修改配置，使用新的 `--output` 目录保留本次结果，而不要覆盖参考记录后仍沿用其原配置说明。
